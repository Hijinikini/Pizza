# Лабораторная работа № 4 — MVP

## Архитектура
- `PizzaModel` — доменные сущности `Pizza` и `SizeDiscount`.
- `DataAccessLayer` — репозитории, Unit of Work и доступ к БД.
- `PizzaLogic` — бизнес-сервисы и фасад `ILogic`/`Logic`.
- `Shared` — интерфейс `IView`, DTO и аргументы событий; не зависит от остальных проектов.
- `Presenter` — `ShowPresenter`, `DtoMapper`, `CompositionRoot`.
- `PizzaWinForms` — WinForms-представление.
- `Pizza` — консольное представление.

## Поток работы
1. View сообщает о действии пользователя событием.
2. Presenter получает событие и вызывает `ILogic`.
3. Фасад бизнес-логики выполняет операцию через специализированные сервисы.
4. Фасад поднимает `PizzasChanged` или `DiscountsChanged` после успешного изменения.
5. Presenter получает уведомление, получает актуальные данные, преобразует их в DTO и передаёт View.

## Запуск
- Для оконного интерфейса запустить проект `PizzaWinForms`.
- Для консольного интерфейса запустить проект `Pizza`.
- Проекты рассчитаны на .NET 8. Для работы БД используется строка подключения LocalDB из `PizzaDbContext`.
